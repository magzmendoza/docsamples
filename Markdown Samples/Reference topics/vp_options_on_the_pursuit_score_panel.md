# Options on the Pursuit Score Panel

Use the options on the Pursuit Score panel to update the generated pursuit score information. 

[[INCLUDE:conrefs/Conref_Dela.md#conref_delanewfeature]]

## Contents

| Field|Description|
| --- | --- |
| **Regenerate** | Click this option to regenerate and refresh the Pursuit Score information. | 
| **Complete missing scoring field/s** | Click this suggestion to display the missing field information that may impact on the Pursuit Score. | 
| **Review firm information** | Click this suggestion to view the firm relationship information, including relationship history, profitability, and past projects. | 
| **Assign missing pursuit roles** | Click this suggestion to assign missing pursuit team roles, such as BD Lead or Proposal Coordinator. | 
| **Assign client owner** | Click this suggestion to assign a client owner. **Note:** A different name is displayed if the **Owner** field has been modified in Screen Designer. |
| **Talk to client owner about client relationship** | Click this suggestion to contact the assigned client owner. **Note:** A different name is displayed if the **Owner** field has been modified in Screen Designer. |
| **Add activity for check-in** | Click this suggestion to open the Activities dialog box to create pursuit-related follow-up actions, such as meetings, check-ins, or other tasks. For more information, see the [Contents of the Activities dialog box]. | 
| **Add quick note** | Click this suggestion to create pursuit-related notes without creating a follow-up activity. However, you can also add more activity information through this suggestion. |
