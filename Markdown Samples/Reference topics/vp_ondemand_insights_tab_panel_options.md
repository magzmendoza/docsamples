# Options on the On-Demand Insights Panel in the New Vantagepoint User Experience

Use the options on the On-Demand Insights tab panel to give you control, flexibility, and clarity when working with manually generated insights.

## Contents of the On-Demand Insights Tab Panel

| Fields | Description |
| --- | --- |
| **Collapse**| Click to temporarily hide the on-demand insight panel. |
| **Maximize/Inline Display**| Click to view the insight inline (side-by-side with the application) or maximize it for a focused review. |
| **Help/Info (i)**| Click to open contextual help for the specific on-demand insight. It provides more information about what the insight shows and how it was generated. |
| **Progress Indicator (spinner icon)**| A spinner appears while an insight is being generated, along with a “Generating Insight…” message. To regenerate the insight later, click **Regenerate** next to the spinner.|
