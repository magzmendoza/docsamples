# Options on the Add Quick Note Dialog Box

Use the options on the Add Quick Note dialog box to provide additional information. 

[[INCLUDE:conrefs/Conref_Dela.md#conref_delanewfeature]]

## Contents

| Field|Description|
| --- | --- |
| **Date** | Click this field to open the Calendar and assign a specific date. | 
| **Contact** | Click this field to search and assign a contact. | 
| **Project** | Click this field to search and assign a project. | 
| **Notes** | The Notes field is already populated with pursuit score details. Click this field to add more information. | 
| **Add More Activity Information** | Click this link to open the Activities dialog box to add more activity details. |
| **Save** | Click this action to save a quick note record. |
