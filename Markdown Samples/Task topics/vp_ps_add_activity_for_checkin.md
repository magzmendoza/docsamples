# Add Activity for Check-in

You can add an activity from the Pursuit Score panel. 

This suggestion lets you schedule a follow-up related to the pursuit. It may be the client owner calling the client to gather more details, a check-in with the pursuit manager, or any other task that helps evaluate the project. Scheduling a specific action keeps the pursuit moving forward instead of stalling.
 
**To add an activity for check-in:**

1. On the left side of the project record, click the **Pursuit Score value** to open the Pursuit Score panel.
2. In the Pursuit Score panel, scroll to the Suggestions section. 
3. Click **Add activity for check-in**. See the Contents of the Activities dialog box (link) for more information.
4. In the Activities dialog box, enter the required information. The **Notes** field is pre-populated with pursuit score details, but you can still add more information if needed.
5. Click **Save**.
