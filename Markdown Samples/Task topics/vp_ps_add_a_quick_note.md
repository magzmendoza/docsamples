# Add a Quick Note

You can add a quick note from the Pursuit Score panel. 

Use this to record information directly on the project so others can see it. For example, you may log that the pursuit scored a certain value on a given date, or document the go/no-go decision based on the score. This creates a visible record of pursuit decisions over time.
 
**To add a quick note:**

1. On the left side of the project record, click the **Pursuit Score value** to open the Pursuit Score panel.
2. In the Pursuit Score panel, scroll to the Suggestions section. 
3. Click **Add quick note**. 
4. In the Add Quick Note dialog box, enter the additional information. 
5. Optional: Click **Add More Activity Information** to provide additional activity details. 
6. Click **Save**.
