# How to Generate a Pursuit Score in the New {{vars.vantagepoint}} Experience

Access the Pursuit Score from an on-demand panel.

[[INCLUDE:conrefs/Conref_Dela.md#conref_delanewfeature]]

## Prerequisite

You should do the following before generating a Pursuit Score:

- Enable the **Customer Intelligence Agent** in [[INCLUDE:conrefs/Settings-Options.md#SETTINGS_DELA_INSIGHTS]].
 
**To generate a Pursuit Score in the new {{vars.vantagepoint}} experience:**

1. In the Navigation pane, select {{INCLUDE:conrefs/Projects hub.md#NP_PROJECTS}}.
2. On the Projects form, search and select a project record.
3. On the left-side of the record, click **Generate Score**. A pursuit score value is generated.
4. Click the pursuit score value, and then click **View Details**. A Pursuit Score panel displays. <div class="note note note_note"><span class="note__title">Note:</span> Click **Regenerate** if you want to refresh the pursuit score value.</div>
5. Verify the contents of the Pursuit Score. It contains the generated pursuit score, different score factors, and actionable suggestions.
6. Click one of the suggested actions below to know if there are any additional details to improve:

    - **Complete missing scoring fields**
    - **Review client information**
    - **Assign missing pursuit roles**
    - **Assign client owner/Talk to client owner about client relationship**
    - **Add activity for check-in**
    - **Add a quick note**
    
    For detailed steps on each suggestion, refer to [How to Work with Pursuit Score Suggestions](../Dela%20Insights/vp_how_to_work_with_pursuit_score_suggestions.md)

7. To refresh the contents of the Pursuit Score details, click **Regenerate**.
