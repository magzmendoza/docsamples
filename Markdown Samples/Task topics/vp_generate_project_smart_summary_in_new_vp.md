# How to Generate a Project Smart Summary in the New {{vars.vantagepoint}} Experience

Access the Project Smart Summary from an on-demand panel.

## Prerequisites

You should do the following before generating a Project Smart Summary:

- You should have access to the New Vantagepoint interface. 
- Enable the **Customer Intelligence Agent** in [[INCLUDE:conrefs/Settings-Options.md#SETTINGS_DELA_INSIGHTS]].
- Enable **AI Generated Summaries** in {{INCLUDE:conrefs/General Settings Options (browser).md#NP_GENERAL_SYSTEM_SETTINGS}}. 
- Enable **Allow Project Smart Summary Access** in {{INCLUDE:conrefs/Security.md#NP_ROLE_SECURITY_SETTINGS}}.
 
**To generate a Project Smart Summary in the new {{vars.vantagepoint}} experience:**

1. In the Navigation pane, select {{INCLUDE:conrefs/Projects hub.md#NP_PROJECTS}}.
2. On the Proejcts form, search and select a project record.
3. Click **Dela Actions**, and then select **Generate Smart Summary**.
4. If it is your first time to generate, a Smart Summary Terms appear, click **Accept and Generate**. A Project Smart Summary panel displays.<div class="note note note_note"><span class="note__title">Note:</span> Each generated Project Smart Summary is displayed in an on-demand panel. Up to four on-demand panels can be displayed at a time. When the limit is reached, the oldest panel will be automatically replaced with the new one.</div>

5. Verify the contents of the Smart Summary.
6. To copy a Smart Summary information to a third-party application, click **Copy**.
7. To refresh the contents of the Smart Summary information, click **Regenerate**.

For more information, see [Contents of the AI-Generated Project Smart Summary Preview](/topics/Business%20Development/Projects/vp_hub_projects_contents_of_the_project_smart_summary_preview.md) and [Project Smart Summary KPIs and Calculations](/topics/Business%20Development/Projects/vp_hubs_projects_project_smart_summary_kpis_calculations.md)
