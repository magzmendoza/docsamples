# Access Ask Dela in the New {{vars.vantagepoint}} User Experience

In the new {{vars.vantagepoint}} user experience, you access Ask Dela from a persistent right-side Context Menu.

**To access Ask Dela in the new user experience:**

1.  Click ![](images/Harmony_Ask_Dela_Icon_New_16x16.png) in the Context Menu.

<div class="note note note_note"><span class="note__title">Note:</span> Starting in 2026.4, when you opt in to the Dela Expansion feature, a "(Preview)" label appears in the Ask Dela title bar, and you'll have access to more {{vars.vantagepoint}} learning content via Ask Dela. The <b>information (i)</b> icon explains the feature's preview status.</div>

For more information, see [Opt-In Features Overview](/topics/Settings%20and%20Configuration/General%20Settings/vp_set_optin.md).
