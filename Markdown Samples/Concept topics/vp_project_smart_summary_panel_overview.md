# Project Smart Summary Panel

The Project Smart Summary panel generates an AI-based summary of a project, including financial health, recent activities, plan details, pursuit information, and key performance indicators (KPIs), to support quick assessment of project status and performance.

{{INCLUDE:conrefs/Use the Smart Summaries Logo Paragraph and Sections.md#P_ED88C3EE16EE44DA9A14DF9D8523B36F}}

## Where to Find Your Project Smart Summary Panel

Project Smart Summary panels appear as on-demand panels in the new Vantagepoint user experience when you generate a Smart Summary from the **Dela Actions** button on a project record. The panel displays the generated Project Smart Summary and allows you to collapse or close as needed.
