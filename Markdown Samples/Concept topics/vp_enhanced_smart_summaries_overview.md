# Enhanced Smart Summaries

Enhanced Smart Summaries provide an improved experience for viewing AI-generated client and project summaries in the new {{vars.vantagepoint}} experience. Instead of displaying summaries in a dialog box, Smart Summaries now open in an on-demand, dockable side panel that allows you to review information while continuing to work within a firm or project record.

This feature is available for both the Client Smart Summary in the Firms hub and Project Smart Summary in the Projects hub. The updated experience improves usability and navigation while preserving the existing Smart Summary experience for users who do not have access to the new Vantagepoint experience or the required Customer Intelligence Agent permissions.

## Prerequisites

To use the enhanced Smart Summaries:

- You should have access to the new {{vars.vantagepoint}} interface where the Smart Summary panel is available.
- You must have the appropriate Customer Intelligence Agent (CIA) permissions.
- You are allowed to access Client Smart Summary and Project Smart Summary in Role security settings.

<div class="note note note_note"><span class="note__title">Note:</span> If you do not have access to the new Vantagepoint experience or the required permissions, you can continue using the existing Smart Summary dialog.</div>

## Key Benefits

Enhanced Smart Summaries help you:

- View AI-generated client and project information without interrupting your workflow
- Keep summary information available while navigating the other areas of Vantagepoint
- Quickly access relevant insights associated with the current firm or project
- Regenerate or copy summary information more easily through actions located at the top of the panel

## Smart Summary Panel

The enhanced Smart Summary experience uses an on-demand panel that integrates with the new {{vars.vantagepoint}} user experience. The panel includes standard panel functionality, such as the ability to resize, collapse, and close the panel as needed.

The Smart Summary panel includes:

- **Generated Date:** Displays when the Smart Summary was last generated
- **Copy:** Copies the Smart Summary content for use in other applications. such as Microsoft Word.
- **Regenerate:** Refreshes the Smart Summary with the latest available information
- **Insights:** Opens related insights for the current firm or project when available

## Multiple Smart Summary Panels

Smart Summaries are displayed as on-demand panels that can remain open while you work. {{vars.vantagepoint}} supports up to four on-demand panels at one time. When you attempt to open a fifth on-demand panel, it prompts you to replace the oldest opened panel.

## Insights Integration

Enhanced Smart Summaries include integration with insights. When relevant insights are available, an Insights button appears within the Smart Summary panel. Selecting this button opens the associated Insights panel filtered to the current record, allowing you to review related information without leaving your current context.
